# Chrome Proxy

Расширение Chrome Manifest V3 для прокси и исключений по сайтам. Действует только в профиле Chrome, где установлено, и не меняет системные настройки или другие приложения.

## Установка

1. Запустите свой SOCKS5-сервер. По умолчанию расширение использует локальный `127.0.0.1:21982`; endpoint задаётся в `PROXY_CONFIG` файла `background.js`.
2. Откройте `chrome://extensions` и включите режим разработчика.
3. Нажмите «Загрузить распакованное расширение» и выберите папку проекта.
4. Откройте Chrome Proxy через значок расширения. Новая установка находится на паузе; включите прокси переключателем.

Расширение не содержит сам сервер или туннель. SOCKS5 используется без логина и пароля; credentials в исходники добавлять не нужно. После изменения файлов перезагрузите расширение на странице `chrome://extensions`.

## Использование

- `ALL`: все публичные сайты идут через прокси.
- `EX`: сохранённые домены и их поддомены открываются напрямую, остальные через прокси.
- Пауза: расширение снимает свои настройки прокси, не удаляя исключения.

Кнопка «Исключить» добавляет текущий домен. Также можно ввести домен вручную, удалить отдельное исключение или очистить список. Редактирование списка на паузе не включает прокси.

Локальные имена и приватные IPv4 остаются прямыми. Для остальных сайтов при недоступном SOCKS5 нет запасного прямого подключения. Значок отражает применение настроек Chrome и не подтверждает доступность сервера или внешний IP. При ошибке отключения переключатель сохраняет прежнее положение, чтобы можно было повторить действие.

## Проверка

Нужен Node.js `24.18.0`. Внешних зависимостей и сборки нет.

```bash
node scripts/check.mjs
```

Команда проверяет синтаксис, manifest и изолированные сценарии расширения. Текущие ограничения описаны в [STATUS.md](STATUS.md).
