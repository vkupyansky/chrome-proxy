# Состояние

Работают общий переключатель, исключения по доменам, управление текущим сайтом и сохранение настроек между запусками. Новая установка выключена; ранее сохранённый выбор имеет приоритет.

Изолированные проверки покрывают PAC, приватные IPv4, границы доменов, сохранение настроек, конкуренцию, ошибки Chrome API, повтор отключения и отсутствие ложного успеха вне расширения.

Реальный Chrome-профиль и внешний трафик этими тестами не изменяются. Доступность прокси-сервера и фактический внешний IP проверяются отдельно владельцем. SOCKS5 endpoint должен быть запущен до включения расширения.
