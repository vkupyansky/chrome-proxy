# Chrome Proxy

Небольшое расширение Chrome для прокси в одном профиле браузера и прямого подключения к выбранным сайтам. Интерфейс на русском, рассчитан на macOS.

В компактном окне находятся режим подключения и правило текущего сайта. На отдельной странице настроек показаны адрес прокси, автоматические правила и список исключений с поиском.

## Установка

Нужен Chrome 123 или новее.

1. [Скачайте ZIP проекта](https://github.com/vkupyansky/chrome-proxy/archive/refs/heads/main.zip) и распакуйте в постоянную папку.
2. Откройте `chrome://extensions` и включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение** и выберите распакованную папку с `manifest.json`.
4. Откройте расширение. Новая установка использует режим **Как в macOS**. Выберите **Авто**, чтобы включить его правила.

Скомпилированные файлы `dist/` уже включены. Для использования расширения не нужны Node.js, npm или сборка.

По умолчанию ожидается работающий HTTP-прокси `127.0.0.1:10809`, например Happ в режиме Proxy. При необходимости измените адрес в **Настройках**. Расширение не запускает сервер прокси или туннель.

## Режимы подключения

- **Авто**: локальные адреса, домены .ru/.su/.рф и сохранённые исключения открываются напрямую; остальные сайты через выбранный прокси. Если прокси недоступен, по умолчанию разрешён переход напрямую.
- **Напрямую**: все сайты в этом профиле используют обычное соединение без прокси. Сохранённые правила остаются на месте.
- **Как в macOS**: расширение снимает своё управление. Chrome использует системные настройки или другое управляющее расширение. В этом режиме тоже может работать прокси.

Кнопка **Открывать напрямую** в компактном окне добавляет домен текущего сайта. Исключение охватывает домен и его поддомены. На странице настроек можно вставить домен или ссылку, найти и удалить отдельную запись. Очистка всего списка требует подтверждения. Правила редактируются в любом режиме, действуют в режиме «Авто».

На странице настроек также доступны:

- Адрес и порт HTTP- или SOCKS5-прокси без авторизации.
- Прямое подключение к локальной сети.
- Прямое подключение к доменам .ru, .su и .рф.
- Разрешение пробовать обычное соединение, если прокси недоступен.

Локальные правила охватывают простые имена, .local/.localhost/.home.arpa, приватные IPv4, loopback, link-local и IPv6 ULA. IP-правила проверяют адреса, указанные прямо в URL; DNS-запросы для классификации доменов не выполняются.

## Обновление

Замените файлы расширения в **той же папке**, затем нажмите перезагрузку его карточки на `chrome://extensions`. Для обычного обновления не удаляйте расширение. Прежний включённый режим и исключения переносятся автоматически; при повреждении сохранённых данных появляется ошибка вместо молчаливого сброса.

Перенос папки может изменить ID расширения и его хранилище. Перезапуск Chrome не нужен.

## Приватность и ограничения

Расширение действует в профиле, где установлено. Оно не меняет сеть macOS, другие профили, Happ или остальные приложения. В нём нет внешних библиотек времени выполнения, аналитики, удалённого кода или сетевых шрифтов.

Разрешения ограничены `proxy` для маршрутизации этого профиля, `storage` для локальных настроек и `activeTab` для чтения домена текущего сайта после нажатия значка. Авторизация на прокси не поддерживается и не требуется.

Российские доменные зоны не определяют владельца сайта или расположение сервера; другие нужные сайты добавляются вручную. Переход напрямую относится к недоступному соединению с прокси; HTTP-ошибка самого прокси не всегда вызывает такой переход. После восстановления прокси Chrome может несколько минут использовать обычное соединение из-за своего кэша неисправных прокси.

Интерфейс показывает применённое правило и состояние управления в Chrome, а не измеренный маршрут каждого запроса.

## Разработка

Используйте Node.js **24.18.0**, закреплённый в [`.node-version`](.node-version).

```sh
npm ci --ignore-scripts
npm run check
```

Единая проверка выполняет Biome с предупреждениями как ошибками, строгую компиляцию TypeScript, проверку manifest, регрессии маршрутизации и контроллера, а также сценарии интерфейса в изолированном профиле Chrome. Для браузерных тестов нужен Google Chrome; при другом пути к исполняемому файлу задайте `CHROME_BIN`.

```sh
npm run format
npm run build
```

`src/` содержит исходники TypeScript, `dist/` — сгенерированный JavaScript, загружаемый Chrome. После изменения исходников включайте пересобранные файлы `dist/` в тот же коммит. Настройки и сообщения проверяются на границах системы, изменения выполняются последовательно. Сначала проверяется фактическая конфигурация Chrome, затем сохраняются настройки. При сбое возвращается прежняя конфигурация и показывается ошибка.

Зависимости разработки: TypeScript, типы Chrome API и Biome. Папка `node_modules/` нужна только для сборки и проверок; после них её можно удалить без влияния на установленное расширение.
