# Разработка

- `background.js` управляет PAC, хранилищем и очередью изменений; `popup.js`, `popup.html` и `popup.css` содержат интерфейс.
- Единственная настройка endpoint находится в `PROXY_CONFIG` внутри `background.js`. Не публикуйте credentials и частные данные туннеля; расширение не запускает сервер прокси.
- Новая установка остаётся на паузе. Существующие `enabled` и `siteRules` сохраняются, редактирование исключений не включает прокси.
- Изменения состояния выполняются последовательно. Переключатель сохраняется после подтверждения Chrome API; ошибка не должна показываться как успешное отключение.
- Для публичных доменов нет запасного `DIRECT`. Локальные диапазоны сопоставляются только с IPv4-литералами; исключение охватывает домен и его поддомены.
- Проверка: `node scripts/check.mjs` на Node.js `24.18.0`. Тесты используют изолированные Chrome API и не меняют пользовательский профиль. Предупреждения считаются ошибками.
